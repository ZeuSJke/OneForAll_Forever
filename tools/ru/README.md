# Русский перевод OneForAll

Форк [OneForAll – Forever](https://github.com/smoergi/OneForAll_Forever) с русским переводом
интерфейса и названий. В основной аддон перевод не принят, поэтому живёт здесь.

- **Ветка `main`** — копия `main` автора без изменений, ничего в неё не коммитим.
- **Ветка `ru`** — `main` плюс перевод. Отсюда собирается аддон.

## Что переведено и откуда

| Файл | Что | Откуда |
|---|---|---|
| `OneForAll/Locales/ruRU.lua` | тексты интерфейса аддона | перевод MakarSikorskyi для 6.2.4 (его PR номер 66 к автору, закрыт без слияния), дальше — свой перевод новых строк |
| `OneForAll/Locales/Names_ruRU.lua` | названия заданий, NPC, объектов, предметов и цели заданий | генерируется `names.py` из русских текстов клиента в [QuestieDB](https://github.com/Questie/QuestieDB) (GPL-3) |
| `OneForAll/Locales/Locale.lua`, `OneForAll.toc` | «Русский» в списке языков, подключение файлов, `Notes-ruRU` | правки в пару строк |

Чего нет в `ruRU.lua`, аддон показывает по-английски, ошибок от этого не бывает. Русские названия
работают, только когда в аддоне выбран русский и клиент игры русский.

## Когда выходит новая версия OneForAll

Нужен только Python 3, без сторонних пакетов. Команды запускаются из корня репозитория.

1. Забрать новую версию автора в `main` и влить её в `ru`:

   ```bash
   git fetch upstream
   git checkout main && git merge --ff-only upstream/main && git push origin main
   git checkout ru && git merge main
   ```

   Конфликты обычно бывают в строке `FLT.LANGUAGES` в `Locale.lua`, в списке файлов `.toc`,
   в `THIRD_PARTY_LICENSES.txt` и `README.md`. Нужно оставить и правки автора, и русские строки.

2. Посмотреть, какие строки интерфейса появились. Образцом служит немецкий перевод
   `deDE.lua`: автор обновляет его в каждой версии.

   ```bash
   py -3 tools/ru/sync_ui.py --check
   ```

   Перевести строки из списка «НЕТ» в файл `tools/ru/new_<версия>.lua`. Формат такой же, как в
   `ruRU.lua`: `["English"] = "Русский",`. Подстановки `%s`, `%d`, `%.1f` должны остаться в том же
   порядке. Стиль: обращение на «вы», без «ё», термины как в соседних строках («ячейка»,
   «Shift+щелчок», «Ценность экипировки»). Потом добавить переводы:

   ```bash
   py -3 tools/ru/sync_ui.py --add tools/ru/new_<версия>.lua --version <версия>
   ```

3. Пересобрать названия по свежей версии QuestieDB (какую берёт автор, видно во второй строке
   `Names_deDE.lua`; лучше брать последний тег QuestieDB):

   ```bash
   py -3 tools/ru/names.py --tag v1.0.15 --check
   py -3 tools/ru/names.py --tag v1.0.15
   ```

4. Проверить и закоммитить:

   ```bash
   py -3 tools/ru/check.py
   ```

5. Собрать архив и поставить. Архив содержит папку `OneForAll`, её нужно положить в
   `World of Warcraft\_forever_\Interface\AddOns`, заменив старую, и полностью перезапустить игру:

   ```bash
   git archive --format=zip -o OneForAll-<версия>-ru.zip ru OneForAll
   ```

## Как устроен `names.py`

Аддон ищет русское название по точному английскому тексту. `names.py` берёт английские тексты из базы
Forever в QuestieDB, а русские — из её l10n-файлов по номеру записи. Тонкость: русские файлы
Forever там скопированы из Classic, а база Forever — это Classic плюс поправки, собранные в самом
Forever (`src/corrections/Forever/traces`). Поэтому русский из основного файла берётся, только если
в Classic под тем же номером тот же английский текст, а для переделанных и новых записей Forever
— из `l10n/Forever/traces`. Если у одного английского названия несколько записей, выбирается та,
чьё немецкое название совпадает с `Names_deDE.lua`.
